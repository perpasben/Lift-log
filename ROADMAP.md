# Roadmap

Ideas that are agreed but not built yet.

## Running (later)
A very simple place to log runs, because running is a casual thing here:
- Log a run by **distance** (5, 10, 15 km, or any number), the date, and optionally the time.
- Quick buttons for the usual distances.
- Runs show up in the History calendar (own colour) and count as a training day for consistency; they are **not** part of the muscle map or the strength trend.
- Keep it light: no pace charts, no GPS, no splits. A list of runs and a weekly/monthly kilometre total is enough.
- The overtraining check could count run days and distance as extra load once this exists.
